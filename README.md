A modern, dark-themed responsive developer portfolio built to showcase engineering projects, certifications, technical skill sets, and professional experience in Artificial Intelligence & Data Science.

---

## ✨ Features

* **🎨 Modern UI/UX:** Dark-mode design with glowing CSS gradient accents and subtle animations.
* **⚡ Dynamic Tech Icons:** Animated, floating technology stack badges embedded in the hero section.
* **📱 Fully Responsive:** Adaptive layout with custom navigation drawer designed for seamless mobile viewing.
* **🎓 Academic Track & Bio:** Highlighting B.Tech coursework at Sri Krishna College of Engineering and Technology (SKCET).
* **🧠 Technical Skill Categories:** Detailed breakdown of ML frameworks, programming languages, web technologies, and cloud tools.
* **📂 Featured Projects:** Clean project cards equipped with GitHub repository links and direct performance metrics.
* **📜 Credentials Gallery:** Structured grid displaying verified cloud and developer certifications.
* **📬 Interactive Contact Section:** Integrated social links and direct email launch pad.

---

## 🛠️ Tech Stack

* **Structure:** [HTML5](https://developer.mozilla.org/en-US/docs/Web/HTML)
* **Styling:** Custom CSS3 (Flexbox & CSS Grid, Animations, Responsive Media Queries)
* **Icons:** [Font Awesome 6](https://fontawesome.com/)
* **Typography:** [Google Fonts](https://fonts.google.com/) (*Poppins*, *Montserrat*, *Fira Code*)
